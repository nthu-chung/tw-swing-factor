# 族群輪動選股策略 — 研究報告

> 2026-07-21 接力研究。資料快照 `SNAPSHOT_END_DATE=2026-06-22`、rebalance 5 日 / 持有 5 檔、
> trend 退場、交易成本計入、逐日淨值。基線 = 上線 `momentum_only`。
>
> 對應程式：`sector_rotation.py`（族群排序 + leader/laggard 選股 + IS/OS + bootstrap）、
> `backtest.py`（新增 `picks_by_date` 注入口，讓外部策略共用回測引擎）。
> 兩個 universe 都跑（top100 / top300）以檢驗穩健性，**全部列出不 cherry-pick**。

## TL;DR — 族群輪動做成選股策略後，沒有穩健的增量 edge

`sector_scan.py` 曾證實**族群動能有樣本外延續性**（OS_IC ret20=0.13 / inst6d=0.11 /
breadth=0.07，全 >0.03）——這是本 repo 唯一 OS 站得住的訊號。但把它**做成可回測的選股
策略**後，**在 IS（唯一能區分策略的段）上贏不過純動能**：

1. **領漲(leader) 不穩健**：IS Sharpe 在 top100 是 1.64（看似小贏基線 1.50），但換到 top300
   直接翻成 **−0.08**。同一策略換 universe 就翻號 = 不是 edge，是小樣本雜訊。且兩個 universe
   的 **IS MaxDD 都比基線深很多**（top100 −29% vs −19%、top300 −44% vs −38%），Calmar 更差。
2. **補漲(laggard) IS 站不住**：top100 IS Sharpe **−0.32**（賠錢）、top300 **0.31**（< 基線 0.59）。
   補漲假設（族群強、個股落後→會補漲）在 IS 上不成立。
3. **OS 全是 beta 不是 alpha**：OS 段 top100 買進持有 +167%/98% 上漲、top300 +119%/94% 上漲。
   所有策略 OS 高 Sharpe（3~5）都是普漲行情，bootstrap CI>0 也只是 beta。**決策看 IS。**
4. **「IC 強 ≠ 回測賺」再次應驗**：族群動能 OS_IC 真的為正，但轉成持倉組合後，族群濾網把
   部位**集中**到少數強勢族群（top100 常就是電子三雄）→ 更集中、回撤更深，risk-adjusted 沒變好。

> **決策：不建議把族群輪動當上線選股策略；維持 `momentum_only`。** 引擎已加 `picks_by_date`
> 注入口（通用、可複用），族群策略程式保留供後續研究。**未動上線 `FACTOR_WEIGHTS`。**

## 1. 策略設計

每個 rebalance 日（全因果、訊號日 T 決定、T+1 開盤進場）：
1. **選強勢族群**：跨族群用 族群動能(ret20 中位) + 法人流(inst6d 中位) + 廣度(breadth，站上
   MA20 比例) 各自當日 rank(pct) 等權合成 `sector_score`，取前 3 名族群（≥5 檔才算族群）。
2. **族群內選股**（兩假設各測一版）：
   - **領漲(leader)**：族群內個股動能 `mom_ret` 最高者 → 強者恆強（族群+個股雙確認）。
   - **補漲(laggard)**：族群內個股動能『落後族群中位』(gap=族群中位−個股>0)、趨勢未壞者
     → 族群已動、個股還沒跟上。
3. **回測**：注入 `picks_by_date` 給 `backtest.backtest_portfolio`，共用同一引擎
   （T+1 開盤、trend 退場、跳空、手續費 0.1425%/證交稅 0.3%、逐日淨值）。

防未來函數：族群聚合與個股特徵（mom_ret/inst_6d/breadth）皆只用當日以前資料；排序在 T、
進場在 T+1；fwd_ret 不進策略；回測鎖 snapshot。

## 4. 回答 human 的問題

| 問題 | 答案 |
|---|---|
| 族群輪動有沒有增量 edge？ | **沒有穩健的增量 edge**。IS 段兩個 universe 都贏不過純動能；看似小贏的 top100 leader 換 universe 就翻號。 |
| 補漲 vs 領漲 哪個 OS 好？ | OS 都被普漲 beta 灌大（laggard 名目最高），**但 OS 不可用來決策**；IS 上兩者都輸基線。 |
| 跟 momentum 冗餘嗎？ | leader 中高度冗餘（corr 0.53~0.72，族群濾網≈把動能集中到強勢族群）；laggard 較獨立(0.38) 但 IS 弱。 |
| 建議上線嗎？ | **不建議。維持 momentum_only。** 引擎的 `picks_by_date` 注入口保留（通用）。 |
| 為什麼族群 OS_IC 為正、策略卻不賺？ | 「IC 強 ≠ 回測賺」：族群濾網把部位**集中**到少數強勢族群 → 更集中、MaxDD 更深、risk-adjusted 沒變好。橫斷面區分力 ≠ 持倉組合的風險報酬。 |

## 5. 誠實限制

1. **僅 2 年、單一多頭 + 一次股災**；族群延續性（OS_IC 0.13）可能含時代紅利，且 OS 太短、太
   普漲，無法當 edge 證據。
2. **族群用 FinMind 官方粗分類**，抓不到主題概念股（功率元件等橫跨多產業）——主題式族群或許
   才是族群輪動真正發力處，但需手工成分清單，本輪未做（列為後續）。
3. **IS 樣本小**（74~127 筆）；top100 leader 的 1.64 與基線 1.50 差距在小樣本雜訊範圍，且被
   top300 的 −0.08 直接否證。守鐵則「小樣本小差距不改決策」。
4. 交易成本已計入；防未來函數、鎖 snapshot；`picks_by_date` 注入不影響 momentum_only 基線
   （已驗證 top100 基線 IS Sharpe 仍為 1.50）。
5. 本報告為研究用途，非投資建議。

## 6. 下一步（若要續攻族群這條線）

1. **主題式族群**（手工成分清單：功率元件、CoWoS、矽光子…）取代官方粗分類——官方分類讓
   「強勢族群」退化成電子大類、與動能冗餘；主題族群才可能有真輪動 alpha。
2. **動能 × 補漲 混合**（利用 laggard 與基線低相關 0.38）看能否在不傷 IS 的前提下降波動——
   但需先讓補漲本身有正 IS edge，目前沒有。
3. 這些都需**更長、含多次空頭的資料**才驗證得動（與前三份研究同一結構性瓶頸）。
